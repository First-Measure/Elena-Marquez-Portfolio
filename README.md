# Elena Marquez — Fictional Test Portfolio

Client production repository created from the First Measure Portfolio Starter.

This is a fictional test portfolio. It does not describe a real person, firm, project, credential, or professional claim.

## Site

The implementation is a framework-free, one-page HTML/CSS/JavaScript portfolio with client-specific architectural compositions and code-native reconstructed evidence diagrams.

- `index.html` — semantic site content and SVG evidence presentations
- `styles.css` — responsive architectural editorial visual system
- `script.js` — accessible progressive-enhancement navigation
- `assets/documents/Elena-Marquez-Resume.docx` — downloadable fictional résumé
- `AGENTS.md` — repository-wide implementation requirements
- `portfolio-starter-IMPLEMENTATION-RULES.md` — design-independence requirements
- `QA-REVIEW.md` — report-only human review protocol

## Run locally

Use Node.js 20 or newer.

```sh
npm install
npx playwright install chromium
npm run validate
```

The validation command checks HTML, local assets and links, browser errors, automated accessibility, navigation behavior, and horizontal overflow at all required viewport widths.

## Evidence status

All displayed project graphics are newly created portfolio reconstructions or illustrative material and are labeled accordingly. The source package did not include publishable photography or original project artifacts.

Unresolved publication permissions, image licensing, final Riverline facts, selected-detail authorship, Mesa affordability and performance information, testimonials, and unsupported outcomes remain excluded.
